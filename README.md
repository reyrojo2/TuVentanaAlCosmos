# 🌌 Tu Ventana Al Cosmos

> Un viaje interactivo a través del universo, el sistema solar y la exploración espacial.

![Preview del sitio](https://github.com/reyrojo2/TuVentanaAlCosmos/blob/a106d8437f42f5f01b96721ada57b8be6ce38727/imagenes/VentanaCosmos.png?raw=true)

## 📄 Descripción

**Tu Ventana Al Cosmos** es un sitio web educativo e inmersivo desarrollado como proyecto para el curso de **Arquitectura de Entornos Web** en **Cibertec** (1er ciclo).

El objetivo del proyecto fue crear una experiencia de usuario fluida y visualmente atractiva utilizando tecnologías web estándar, demostrando el dominio de los fundamentos del desarrollo frontend.

🔗 **Demo en vivo:** [Visitar Sitio Web](https://reyrojo2.github.io/TuVentanaAlCosmos/index.html)

## 🚀 Características Principales

* **Reproducción de Música Persistente:** 🎵 El sitio cuenta con un reproductor de audio integrado. Se utiliza `localStorage` para guardar el minuto exacto de reproducción, permitiendo que la música continúe sin interrupciones al navegar entre las diferentes páginas HTML.
* **Ventanas Modales:** Interfaz interactiva con pop-ups informativos creados mediante manipulación del DOM.
* **Diseño Temático:** Estética espacial inmersiva con fondos animados y efectos visuales.
* **Contenido Educativo:** Secciones dedicadas al Sistema Solar, Historia de la Astronomía y Exploración Espacial.
* **Responsive en Escritorio:** Se aplicó propiedades nativas en CSS para que el sitio se vea de la misma forma en cualquier PC. Únicamente en escritorio es responsive.

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido 100% con tecnologías **Vanilla** (Puras):

* **HTML5:** Estructura semántica.
* **CSS3:** Estilos, animaciones y diseño responsivo.
* **JavaScript (ES6+):** Lógica del reproductor, persistencia de datos y manipulación del DOM.
